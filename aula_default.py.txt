1. VISÃO GERAL DA ARQUITETURA
================================================================================

Este projeto segue o padrão MVC (Model-View-Controller):

┌─────────────────────────────────────────────────────────────────────────────┐
│                            ARQUITETURA MVC FLASK                              │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                             │
│   MODELS (app/models/)          VIEWS (app/templates/)    CONTROLLERS       │
│   ─────────────────             ────────────────────     (app/controllers/) │
│   • forms.py      ──────────►   • base.html             • default.py  ◄──── │
│   • tables.py                    • user.html             (ESTE ARQUIVO)     │
│                                  • formulario.html                              │
│                                  • 404.html                                     │
│                                  • 500.html                                     │
│                                                                             │
│   Fluxo: Request → Controller → Model → Template → Response                 │
│                                                                             │
└─────────────────────────────────────────────────────────────────────────────┘

O arquivo default.py é responsável por:
- Receber requisições HTTP
- Processar lógica de negócio (validação, sessão, flash)
- Renderizar templates com dados
- Retornar respostas HTTP apropriadas

2. IMPORTS E DEPENDÊNCIAS
================================================================================

CÓDIGO:
-------
from app import app
from flask import (
    render_template,  # Renderiza templates HTML com variáveis
    url_for,          # Gera URLs para rotas nomeadas
    request,          # Acessa dados da requisição HTTP
    redirect,         # Redireciona para outra rota
    session,          # Armazena dados entre requisições
    flash             # Exibe mensagens temporárias
)
from datetime import datetime, timezone
from app.models.forms import FormularioTeste

EXPLICAÇÃO DETALHADA:
---------------------

▸ from app import app
  Importa a instância da aplicação Flask criada em app/__init__.py.
  É o objeto central que gerencia rotas, configuração e extensões.

▸ from flask import ...
  Funções utilitárias do Flask:
  
  • render_template(template, **context)
    - Procura templates em app/templates/
    - Processa Jinja2 com as variáveis passadas
    - Retorna string HTML renderizada
  
  • url_for(endpoint, **values, _external=False)
    - Gera URL para uma rota nomeada (nome da função)
    - _external=True gera URL absoluta (com domínio)
    - Ex: url_for('user', name='João') → '/user/João'
  
  • request
    - Objeto global com dados da requisição atual
    - request.method, request.form, request.args, etc.
    - Não usado diretamente aqui (WTForms abstrai)
  
  • redirect(location, code=302)
    - Retorna resposta de redirecionamento HTTP
    - location pode ser string ou url_for()
    - Código 302 = Found (redirecionamento temporário)
  
  • session
    - Dicionário-like que persiste entre requests
    - Armazenado em cookie assinado (client-side) por padrão
    - Requer SECRET_KEY configurada
    - session['chave'] = valor  |  session.get('chave', default)
  
  • flash(message, category='message')
    - Armazena mensagem na sessão para exibição única
    - Recuperada com get_flashed_messages() no template
    - Categorias: 'message', 'error', 'warning', 'info', 'success'

▸ from datetime import datetime, timezone
  - datetime.now(timezone.utc) → datetime atual com timezone UTC
  - Usado para demonstrar Flask-Moment no template user.html

▸ from app.models.forms import FormularioTeste
  - Importa a classe de formulário WTForms definida em models/forms.py
  - Contém campos: name (StringField), submit (SubmitField), remember_me (BooleanField)

3. ROTA DE USUÁRIO (/user e /user/<name>)
================================================================================

CÓDIGO:
-------
@app.route('/user/<name>')
@app.route('/user', defaults={'name': None})
def user(name):
    path = url_for('user', name=name, _external=True)
    return render_template('user.html',
                           name=name,
                           path=path,
                           current_time=datetime.now(timezone.utc))

EXPLICAÇÃO:
-----------

▸ DOIS DECORADORES @app.route:
  - @app.route('/user/<name>')  → Captura /user/QualquerCoisa
  - @app.route('/user', defaults={'name': None})  → Captura /user (sem parâmetro)
  
  O Flask testa rotas na ordem de definição. A mais específica deve vir PRIMEIRO.

▸ PARÂMETRO <name>:
  - Parte dinâmica da URL (converter padrão: string)
  - Outros conversores: <int:id>, <float:price>, <path:path>, <uuid:id>
  - Valor passado como argumento da função

▸ defaults={'name': None}:
  - Define valor padrão quando a rota não tem o parâmetro
  - Permite que a MESMA função atenda ambas as URLs

▸ url_for('user', name=name, _external=True):
  - Gera URL ABSOLUTA (ex: http://localhost:5000/user/João)
  - Útil para APIs, emails, demonstração
  - Sem _external=True → URL relativa (/user/João)

▸ VARIÁVEIS PASSADAS AO TEMPLATE:
  - name: string ou None
  - path: URL absoluta da rota atual
  - current_time: datetime UTC para Flask-Moment

TEMPLATE user.html (resumo):
----------------------------
{% extends 'base.html' %}
{% block page_content %}
  {% if name %}<h1>Hello, {{name}}</h1>{% else %}<h1>Hello, pessoa qualquer.</h1>{% endif %}
  <h2>{{ path }}</h2>
  <h3>{{ moment(current_time).fromNow(refresh=True) }}.</h3>
  <h3>{{ moment(current_time).format('LLL') }}.</h3>
{% endblock %}

Flask-Moment (moment.js) formata datas no navegador do cliente!

4. MANIPULADORES DE ERRO (404 E 500)
================================================================================

CÓDIGO:
-------
@app.errorhandler(404)
def page_not_found(e):
    return render_template('404.html'), 404

@app.errorhandler(500)
def internal_server_error(e):
    return render_template('500.html'), 500

EXPLICAÇÃO:
-----------

▸ @app.errorhandler(código):
  - Registra função para tratar erros HTTP específicos
  - 404 = Not Found (rota não existe)
  - 500 = Internal Server Error (exceção não tratada)

▸ RETORNO TUPLA (template, status_code):
  - ESSENCIAL: Segundo elemento define o código HTTP
  - Sem isso, retornaria 200 OK mesmo para página de erro!

▸ PARÂMETRO 'e':
  - Objeto de exceção (werkzeug.exceptions.NotFound, etc.)
  - Pode ser logado: app.logger.error(f'Erro 404: {e}')

TEMPLATES DE ERRO:
------------------
404.html e 500.html herdam de base.html e mostram mensagens simples.
Em produção, personalize com design amigável e links de navegação.

6. ROTA DE FORMULÁRIO (/formulario) - O MAIS IMPORTANTE
================================================================================

CÓDIGO COMPLETO:
----------------
@app.route('/formulario', methods=['GET', 'POST'])
def formulario():
    form = FormularioTeste()
    
    if form.validate_on_submit():
        old_name = session.get('name')
        if old_name is not None and old_name != form.name.data:
            flash('Parece que você mudou o nome.')
        session['name'] = form.name.data
        return redirect(url_for('formulario'))
    
    return render_template('formulario.html',
                           form=form,
                           name=session.get('name'))

EXPLICAÇÃO PASSO A PASSO:
-------------------------

▸ methods=['GET', 'POST']:
  - Permite ambas as verbos HTTP na mesma rota
  - GET: Exibe formulário
  - POST: Processa submissão

▸ FormularioTeste() - Instanciação:
  - No GET: Cria formulário vazio
  - No POST: WTForms popula automaticamente com request.form
  - CSRF token validado automaticamente (requer SECRET_KEY)

▸ form.validate_on_submit():
  Retorna True SOMENTE se TODAS as condições:
  1. request.method == 'POST'
  2. CSRF token válido
  3. Todos os validadores passam (DataRequired no campo 'name')
  
  Se False: Cai no render_template final (re-exibe com erros)

▸ FLUXO PRG (Post/Redirect/Get):
  ┌────────────────────────────────────────────────────────────────────────┐
  │                        PADRÃO PRG                                      │
  ├────────────────────────────────────────────────────────────────────────┤
  │                                                                        │
  │   USUÁRIO                    SERVIDOR                                  │
  │   ──────                    ────────                                   │
  │     │                        │                                         │
  │     │── GET /formulario ───►│  Retorna formulário vazio                │
  │     │◄──── HTML ────────────│                                          │
  │     │                        │                                         │
  │     │── POST /formulario ──►│  validate_on_submit() = True             │
  │     │   (dados do form)     │  session['name'] = 'João'               │
  │     │                        │  redirect(url_for('formulario'))        │
  │     │◄── 302 Redirect ──────│  Location: /formulario                  │
  │     │                        │                                         │
  │     │── GET /formulario ───►│  render_template com session['name']    │
  │     │◄──── HTML ────────────│  (nome preenchido, sem reenvio ao F5)   │
  │     │                        │                                         │
  └────────────────────────────────────────────────────────────────────────┘

  VANTAGENS DO PRG:
  - Evita reenvio de formulário ao recarregar página (F5)
  - Separa processamento (POST) de exibição (GET)
  - URLs limpas no histórico do navegador

▸ session.get('name'):
  - Recupera valor ou None (não lança KeyError)
  - Dados persistem enquanto sessão ativa (cookie assinado)

▸ flash('Parece que você mudou o nome.'):
  - Armazena mensagem na sessão com categoria 'message'
  - Exibida UMA VEZ no próximo request
  - Template base.html usa get_flashed_messages() para mostrar

▸ session['name'] = form.name.data:
  - Salva nome validado na sessão
  - form.name.data = valor limpo/validado do campo

TEMPLATE formulario.html:
-------------------------
{% extends 'base.html' %}
{% import 'bootstrap/wtf.html' as wtf %}

{% block page_content %}
<div class="bem-vindo">
    {% if name %}<h1>Bom dia {{ name }}</h1>
    {% else %}<h1>Identifique-se no Campo abaixo.</h1>{% endif %}
</div>
<div class="form2">
    {{ wtf.quick_form(form) }}
</div>
{% endblock %}

wtf.quick_form(form) renderiza TODO o formulário Bootstrap automaticamente!

9. COMO TESTAR CADA FUNCIONALIDADE
================================================================================

PRÉ-REQUISITOS:
---------------
$ pip install -r requirements.txt
$ python run.py  (ou flask run)

TESTES MANUAIS:
---------------

1. ROTA INDEX (/)
   $ curl http://localhost:5000/
   → Deve redirecionar (302) para /user/Julio

2. ROTA USER SEM NOME (/user)
   $ curl http://localhost:5000/user
   → "Hello, pessoa qualquer."

3. ROTA USER COM NOME (/user/SeuNome)
   $ curl http://localhost:5000/user/Maria
   → "Hello, Maria" + URL absoluta + data formatada

4. ROTA INEXISTENTE (404)
   $ curl http://localhost:5000/naoexiste
   → HTML do 404.html com status 404

5. FORMULÁRIO - GET INICIAL
   $ curl http://localhost:5000/formulario
   → HTML com formulário vazio, "Identifique-se no Campo abaixo."

6. FORMULÁRIO - POST VÁLIDO
   $ curl -X POST -d "name=João&submit=Submit" \
        -H "Content-Type: application/x-www-form-urlencoded" \
        http://localhost:5000/formulario
   → Redirect 302 para /formulario
   
   $ curl http://localhost:5000/formulario  (após redirect)
   → "Bom dia João" + formulário com nome preenchido

7. FORMULÁRIO - MUDANÇA DE NOME (FLASH)
   $ curl -X POST -d "name=Pedro&submit=Submit" ... /formulario
   → Redirect
   
   $ curl http://localhost:5000/formulario
   → Flash message "Parece que você mudou o nome." + "Bom dia Pedro"

8. FORMULÁRIO - VALIDAÇÃO FALHA (nome vazio)
   $ curl -X POST -d "name=&submit=Submit" ... /formulario
   → Re-renderiza formulário com erro "This field is required."

TESTE NO NAVEGADOR (RECOMENDADO):
---------------------------------
1. Acesse http://localhost:5000/
2. Navegue para /user, /user/SeuNome
3. Acesse /formulario, preencha, submeta
4. Recarregue página (F5) - não deve reenviar
5. Mude o nome - veja flash message
6. Acesse URL inexistente - veja 404 personalizada

MELHORIAS SUGERIDAS:
--------------------

1. BLUEPRINTS (Modularização)
   ┌─────────────────────────────────────────────────────────────────────────┐
   │ Em vez de tudo em default.py, use Blueprints:                           │
   │                                                                         │
   │ app/controllers/                                                        │
   │   __init__.py                                                           │
   │   main.py          # Rotas principais (/, /user)                       │
   │   auth.py          # Login, logout, registro                           │
   │   api.py           # Endpoints REST/JSON                               │
   │                                                                         │
   │ app/__init__.py:                                                        │
   │   from app.controllers.main import main_bp                             │
   │   from app.controllers.auth import auth_bp                             │
   │   app.register_blueprint(main_bp)                                      │
   │   app.register_blueprint(auth_bp, url_prefix='/auth')                  │
   └─────────────────────────────────────────────────────────────────────────┘

2. VALIDAÇÃO MAIS ROBUSTA
   - Adicionar Length(min=2, max=50) no campo name
   - Validar caracteres permitidos (Regexp)
   - Sanitização de entrada (bleach, markupsafe)

3. SESSÃO NO LADO DO SERVIDOR (Produção)
   - Flask-Session com Redis/Memcached
   - session_interface configurada
   - Mais seguro, escalável

4. FLASH MESSAGES COM CATEGORIAS
   flash('Sucesso!', 'success')
   flash('Erro!', 'error')
   flash('Atenção!', 'warning')
   
   No template:
   {% for category, message in get_flashed_messages(with_categories=true) %}
     <div class="alert alert-{{ category }}">{{ message }}</div>
   {% endfor %}

5. TRATAMENTO DE ERRO GLOBAL
   @app.errorhandler(Exception)
   def handle_exception(e):
       if isinstance(e, HTTPException):
           return e
       return render_template('500.html'), 500

6. LOGGING
   import logging
   if not app.debug:
       logging.basicConfig(filename='error.log', level=logging.ERROR)

7. TESTES AUTOMATIZADOS
   import pytest
   
   def test_formulario_get(client):

       assert response.status_code == 200
       assert b'Identifique-se' in response.data

       response = client.get('/formulario')
